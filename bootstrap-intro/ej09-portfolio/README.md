# Portfolio de Joaquín Gutiérrez

Portfolio profesional desarrollado con **HTML5 y Bootstrap 5.3** en el módulo Diseño de Interfaces Web (2.º DAW).

🔗 **Web publicada:** https://joaquingual2007-dot.github.io/joaquingual2007-dot-ejercicios-bootstrap-1/

## Tecnologías
- HTML5
- CSS3
- Bootstrap 5.3
- Bootstrap Icons 1.13
- JavaScript

## Estructura del proyecto
```
index.html          ← Página principal del portfolio
css/estilos.css     ← Hoja de estilos personalizada
js/main.js          ← Lógica de interacción y validación
img/                ← Imágenes y capturas de proyectos
docs/               ← Documentación y CV en PDF
```
